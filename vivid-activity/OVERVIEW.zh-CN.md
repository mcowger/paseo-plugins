彩色活动行把聊天里 Agent 的思考行和工具调用行重绘成紧凑、按颜色区分的活动行。每类步骤都有自己的颜色和图标，从紫色的思考、蓝色的读文件，到绿色的改文件、橙色的命令。每行还会显示自己的状态：运行中是蓝色转圈（或星芒、光球、点阵），等你批准或等你回答时琥珀色闪动，失败时变红（命令会附上退出码），完成时绿光短暂一闪。

一段思考和工具步骤全部完成后，会收成一行摘要，写明步数、每类的数量、失败数、总用时以及改了什么，例如 `3 files +12 −4` 和五格改动条；点一下这一行，先列出每个文件和失败的命令，再列出各步。Agent 还在工作时，只有运行中、等你批准和失败的步骤以及最近两步保持显示。在你看着跑的一轮里，最后一个摘要下面会显示这一轮的输入、缓存和输出 Token。每行都显示这一步的用时，运行中实时走表。一轮很长时，你的提问会钉在最新一段活动的上方。

本插件基于 Matt Cowger 的 Colorful Agent Activity；改动汇总改编了 Hieu Le 的 paseo-chat-polish 中的代码。

## 活动行显示什么

展开一行，可以看到高亮的命令及其输出和退出码、带行号的读文件结果、着色的 diff、Agent 读过的图片预览，以及 Paseo 工具和 GitHub、Exa 结果的专门视图。命令输出不显示终端转义序列，但保留颜色。Claude Code 的后台任务通知和 Pi 扩展的通知会变成简短的本地化行，按结果着色。定时任务详情里的时间按你设备的时区显示。计划卡、任务清单、审批卡和其他插件的卡片（如 Bots 的提案）保持原样，一段折叠在它们这里结束。

## 设置

无需配置。需要 Paseo 0.11.1 或更高版本。从「设置 → 插件」、App 侧边栏的「彩色活动行」，或命令面板里的
「打开彩色活动行设置」都能打开同一页设置：

- 语言：默认跟随系统（设备语言），也可选英文、简体中文，或 `~/.paseo/plugin-data/vivid-activity/locales/` 里你自己的翻译。
- 接管：全部（默认）、仅思考行或关闭。
- 完成后折叠连续的思考与工具行：默认开。
- 行密度：紧凑（默认，行间 4 px）或标准（10 px）。
- 淡出强度：全强度（默认）、65%、45% 或 30% —— 已完成的行退到该透明度，悬停、聚焦或展开即恢复；没有可展开内容的行保持全强度。已结束的折叠摘要同样变淡，展开或悬停即恢复。
- 钉住本轮提问：默认开。
- 调色板：鲜明（默认）、跟随主题色、柔和或高对比。
- 运行中动画：转圈（默认）、星芒、光球、点阵 · 蛇形或点阵 · 闪烁，附实时预览。
- 代码字体：字体（网页、桌面端）、字号、行距。
- 命令着色：展开时（默认）或始终——行头的 shell 命令带主题的语法色。
- 折行 diff 行：默认关（长 diff 行横向滚动）；开则折到可用宽度。
- 思考行：实时跟随输出（默认关），窗口 5–500 行（默认 20）；每行的「展开全部」仍可看全文。
- 跟随最新输出：按区域分开（命令输出、工作树与子 Agent 日志、任务清单、浏览器），默认全开。行仍在运行时，展开的明细停在最新输出，长输出显示最后 20 行；已完成的行展开后停在顶部。
- 展开方式：每类行可选总是展开、只展开最新、只展开失败或默认收起。含失败的折叠摘要默认展开。

设置页顶部的预览卡实时呈现强度、配色与折行设置的样本行。

设置保存在 daemon 上，对每台连接的设备生效；升级时保留旧版本保存的设置。Agent 的输出、提示词和路径保留原文。

## 数据与权限

- 为了折叠行和计时，插件的服务端部分在 daemon 内读取你正在查看的 Agent 的时间线，并向 App 发送一份精简的索引：每行的位置、结束时间、类型、状态和类别，工具调用 ID 和轮次 ID，文本长度，思考文本的短哈希，加删行数及每个文件路径的短哈希，失败命令的退出码，以及你看着跑的轮次的 Token 数字。索引里不含任何文本、路径、命令或工具输出。对于钉住的提问，它会发送那条消息的文本。
- Token 数字来自 Paseo 保存的 Agent 记录。为了按 Provider 解读这些数字，服务端部分会读取 daemon 的 `config.json`，只保留每个自定义 Provider 的 `extends`；Codex 系的轮次运行时，它还会在 daemon 内订阅运行中 Agent 的更新，把每次请求的用量都累加起来。
- 为了预览 Agent 读过的图片，它只读取该 Agent 工作目录或系统临时目录内、不超过 3 MB 的普通文件，读取前先解析链接。不是图片的文件最多只读前 32 字节。
- 对于 Paseo 的「新建 Agent」行，在 App 处于前台、这一行在屏幕上时，服务端部分会根据新 Agent 时间线的最后 8 条发送三行短摘要，新 Agent 在另一台连接的主机上时向那台主机询问；已关闭或已归档的 Agent 只在你点「查看动态」时才读取，因为读取会加载它。
- 有运行中的行在屏幕上且 App 在前台时，插件会订阅运行中 Agent 的更新，这样一有审批请求，行就会变成琥珀色。
- 插件自己不发网络请求、不启动进程、不读取凭据；它只在自己的插件数据文件夹里写入语言模板和状态。环境变量方面，它用 PASEO_HOME 和 HOME 定位这个文件夹和 daemon 配置，用 TMPDIR 和 HOME 做图片检查。
- 从 Git 安装时会运行一个准备步骤，从公共 npm 仓库安装两个版本由 lockfile 锁定的包：Paseo 的协议包，以及用于高亮的 Prism。

## 已知限制

- Paseo 把每个时间线行交给按 ID 顺序第一个返回结果的插件：同样重绘这些行的插件（如 Beautiful Chat 或 Colorful Agent Activity）会把行拿走，所以请只用其中一个。
- 接管工具行时，Paseo 的「摘要」模式不再合并工具调用，文件路径不能点开，手机上的工具详情改为在行内展开；把「接管」设为「仅思考行」或「关闭」即可恢复这些。
- Paseo 只记录每一步结束的时间，所以一行的用时从上一步结束时算起。
- 只显示确切的行数。写入、删除、被截断的 diff 和 Codex 补丁（Paseo 只保留它们的第一个文件）都记为未计行数的改动。
- 本轮 Token 只在 Claude 系、Codex 系和 ACP 系的 Provider 上显示，并且只限运行时你看着的轮次；插件重载或 daemon 重启之后不再显示。
- 行的折叠和展开状态只在本次会话里记住。
- 子 Agent 自己的聊天视图不折叠，也不计时。
